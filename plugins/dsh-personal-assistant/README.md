# DSH Personal Assistant

DeepSeek Harness 的本地个人助手插件，版本 0.1.0-alpha.1，MIT。

提供长期记忆、跨项目经验关联、自动整理和撤回、内部日历与 ICS、任务执行、工具版本管理，以及微信官方机器人入口。所有业务内容、附件和配置集中保存在用户选择的数据目录；微信凭据保存到本机系统安全存储。

适配 DSH 0.2.1-rc.5，Node.js 24.9 以上。安装后在 DSH 原生“个人助手”工作区对话；其他工作区同样可以生成和召回共享记忆。“助手管理”只提供记忆、项目、日历、任务、工具、收件箱和设置。设置中可选择数据目录和宿主已配置的模型。插件只在 DSH 运行期间工作，恢复后补处理。

默认普通对话归档保留 90 天，变更撤回保留 72 小时。撤回归并会保留后续人工修改。任务执行结束后进入待核对；工具草稿启用后才能执行。

微信：点击“连接微信”，扫码绑定自己的账号。本机重启自动恢复连接；新设备重新扫码。附件最大 20 MB；发送结果不明时进入收件箱，避免自动重复发送。真实微信账号由用户绑定后验收。

迁移：在设置中导出业务目录，把导出目录移到新设备，再浏览选择该目录，微信重新扫码。不要让两台设备同时写一个目录。外部工作目录和外部工具依赖需要重新指定。DSH 原生日志和模型账户仍由宿主管理；迁移后通过新的原生对话使用已保存的记忆，插件没有独立聊天页面。

源码、设计与验收记录：[McLinWxl/dsh-personal-assistant](https://github.com/McLinWxl/dsh-personal-assistant)。

本版本为 alpha，已进行 macOS 真实宿主验证；Windows、Linux 原生操作与微信真实收发需继续验收。依赖许可见 THIRD_PARTY_NOTICES.md。
