# 界面与扫码连接

更新：2026-11-04。适用于 `0.1.0-alpha.1`。

## 页面结构

插件保留记忆、项目、日历、任务、工具、收件箱和设置七个管理入口。对话继续使用 DSH 原生工作区与会话页面。

- 页面采用统一内容宽度、标题与操作区、筛选区和内容区。宽窗口使用多列卡片，窄窗口自动变为单列。
- 任务使用整行卡片呈现名称、状态、摘要和操作。任务与工具的执行记录各自进入次级页面，支持返回、查看结果和打开 DSH 会话。
- 执行记录显示对应任务或工具名称、时间与状态，避免直接展示内部标识。
- 收件箱按“通知”和“整理记录”切换；变更详情与撤回操作保留在对应记录中。
- 设置分为助手工作区、记忆与维护、数据与迁移、微信。桌面使用侧边分类，窄窗口改为横向分类。
- 表单、弹窗、按钮、边距、字号、颜色和焦点状态统一；删除操作收进编辑弹窗。页面只保留必要标题、数据、操作与反馈。

## 默认值和选择控件

| 设置 | 默认显示与操作 |
|---|---|
| 模型 | 跟随 DSH，并显示当前模型；下拉列出实际可用模型 |
| 基础助手 | 跟随 DSH，并显示当前助手；下拉选择已有预设 |
| 工作目录 | 数据目录下的 `projects/workspace/`；原生目录浏览，可恢复默认 |
| 数据目录 | 显示当前完整路径；浏览选择后再应用 |
| 导出目录 | 预填带时间戳的新目录；选择父目录后生成新子目录 |
| 时区 | 显示当前设置，提供时区选框 |
| 每日整理时间 | 默认 03:00，提供小时选框 |
| 普通原文保留 | 默认 90 天，可调整 |
| 撤回时长 | 默认 72 小时，可调整 |
| 处理预算 | 默认值直接显示，收进高级设置 |

“跟随 DSH”在内部仍表示动态继承，不把当前模型硬编码成永久选择。已保存但当前不可用的模型或预设保留原值并标记不可用，不静默改选。目录浏览取消时保持原值，不显示成功反馈。

## 微信登录和设备迁移

新连接直接生成官方二维码，由用户扫码确认，无需插件迁移口令。凭据通过 `@napi-rs/keyring` 写入系统安全存储：macOS Keychain、Windows Credential Manager、Linux Secret Service。Linux 需要可用且已解锁的 Secret Service；不可用时显示错误，不降级为明文文件或仅存在于内存的存储。

凭据按插件数据集身份分别管理，本机重新加载插件时读取并恢复连接。业务目录包含记忆、任务、工具、附件和设置；新设备没有对应系统凭据，需要重新扫码。连接状态接口不返回 token。断开连接会删除该数据集的本机登录凭据并重置通信队列。

旧版加密凭据仅提供兼容恢复入口；输入旧口令成功后转存系统安全存储。新的连接不再写入旧凭据文件。

## 本轮验证

使用隔离 DSH 配置和合成资料检查页面，正式用户目录未导入测试内容。

- 1180 × 800：记忆卡片、任务主页面、任务执行记录、结果弹窗、工具执行记录、设置分类和整理记录正常显示。
- 520 × 800：设置转为单列，分类横排；日历月视图、日程列表与编辑弹窗可操作，内容未被窗口截断。
- 任务历史与工具历史分别显示对应记录；主页面不再堆叠历史。
- 模型、预设、工作目录和维护参数显示实际值；隔离配置未带入模型凭据，原模型显示不可用且保留选择。正式桌面端下拉实际列出已配置模型，默认显示当前模型和内置助手。
- macOS 原生目录浏览可打开、定位并选择当前工作目录，选中路径回填表单；恢复默认目录后保留自动设置。
- macOS 下使用 DSH 自带 Node 24.21.0 完成系统凭据写入、创建新读取实例、读回和删除；测试条目已清理。
- 自动测试覆盖无插件口令的二维码登录、系统凭据保存、重启读取、断开删除、数据集隔离、设备无凭据以及存储错误。
- 用户已在手机扫码确认，真实 DSH 显示“已连接”；另一个 DSH 运行时进程可从 macOS 系统钥匙串读回登录凭据与主人绑定信息，验证输出不包含账号或 token。
- 当前尚无实际收件记录；微信消息往返和登录后的重载恢复等待测试消息完成后验证。Windows 和 Linux 系统凭据及原生目录选择尚未实机验证。

根项目 37 项、插件 43 项测试通过；DSH 自带 Node 24.21.0 下的 43 项测试也通过。TypeScript、构建和独立安装包检查通过；最终安装包包含 17 个文件，已通过 DSH 官方 CLI 安装并重新加载。

源码类型检查、构建、自动测试和安装包检查见 [实施与验收](11-implementation-progress.md)。公开发布状态见 [发布流程](10-distribution.md)。
